# Connect 2 manual

Static Leptos page of the instance manual. Two orgs, one desk. No hub and no model call.

```
trunk serve --open
```

Open `http://127.0.0.1:8081` for midnight, or `http://127.0.0.1:8081/cronos` for cronos. The path is the org. There is no org tab. The box list is that org only. Copy uses the clipboard.
